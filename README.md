# Tank Wars

A multiplayer tank battle game for phones and laptops — up to 12 players in the browser.

- **Play on the same Wi-Fi:** double-click `start.bat` on the laptop, then scan the QR code with your phone.
- **Play online:** deploy this folder to Hugging Face Spaces (Docker) or Render (Node).

Controls: left thumb drives, right thumb aims and fires. Laptop: WASD + mouse.
